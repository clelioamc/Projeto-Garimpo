# Garimpo — código-fonte

Este pacote contém o código do app e a estrutura pnpm necessária para navegar pelo projeto no VS Code. As pastas de dependências instaladas, cache e arquivos temporários foram removidas para reduzir o tamanho do download.

## Onde começar

- Explorar anúncios: `artifacts/mobile/app/(tabs)/index.tsx`
- Favoritos: `artifacts/mobile/app/(tabs)/favorites.tsx`
- Publicar anúncio: `artifacts/mobile/app/(tabs)/sell.tsx`
- Detalhes do anúncio: `artifacts/mobile/app/listing/[id].tsx`
- Dados locais e favoritos: `artifacts/mobile/contexts/MarketplaceContext.tsx`

O app foi escrito em TypeScript com React Native e Expo.
